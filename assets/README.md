# Historical image credits

The site uses two locally stored, public-domain photographs as subtle background textures. Keeping the files in the repository makes the GitHub Pages site self-contained.

- `basketball-1901-purdue.jpg` — *Purdue basketball 1901*, a Purdue yearbook photograph. Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Purdue_basketball_1901.JPG). Listed as public domain in the United States.
- `basketball-1909-nara.jpg` — *Basketball Team, Standing 1909*, from the U.S. National Archives. Source: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Basketball_Team,_Standing_1909_-_NARA_-_251737.jpg). Marked with the Public Domain Mark.

The images are used with a light overlay and low visual contrast so the historical context supports, rather than competes with, the data.

The report cover also uses a remote championship celebration image of Michigan after winning the 2026 NCAA men’s basketball championship. The image is served by Gray/WILX; see the [championship coverage](https://www.wilx.com/2026/04/07/michigan-basketball-captures-2026-national-championship-with-a-69-63-win-over-uconn/) for the source and rights information.
